# albertinefelipe.com

Portfolio of Albertine Felipe, product designer who builds.

Designed and built in code with Next.js, TypeScript, Tailwind CSS and Motion, together with Claude Code.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Where things are
- `DESIGN.md` the visual system and its tokens
- `DECISIONS.md` why things are the way they are
- `CLAUDE.md` working rules for the AI pair
- `docs/` working material
